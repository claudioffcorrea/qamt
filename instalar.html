2 Crear el marcador

  1. Arrastra el botón azul a la barra de marcadores.
  2. Si no puedes arrastrar: Ctrl+Shift+O → clic derecho en la barra → Agregar página → pega el código en el campo URL.
  3. Entra a cualquier sitio web y pulsa el marcador.
Editar una herramientaCambias el archivo en tools/, haces commit y listo. El marcador no se toca nunca: siempre lee la última versión publicada.

3 Si algo falla

  • Abre core.js de tu ruta base en otra pestaña: si ves el código, el sitio sirve.
  • GitHub Pages tarda entre uno y dos minutos en publicar después de cada commit.
  • Las URLs de raw.githubusercontent.com y las que contienen /blob/ no funcionan: el navegador no ejecuta ese contenido.
